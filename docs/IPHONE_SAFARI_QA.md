# 同じWi-FiからiPhone Safariで確認する

Phase 1の実機確認用です。PC上のビルド済みSPAとローカルWorkerをLAN内で提供します。Cloudflareアカウント、D1、デプロイ、インターネット向けトンネルは使いません。

## 起動

PCとiPhoneを同じ信頼できるWi-Fiに接続し、リポジトリのフォルダで実行します。

```sh
pnpm install --frozen-lockfile
pnpm build
pnpm preview:lan
```

端末に表示される`Network: http://...:4174/`をiPhoneのSafariで開いてください。複数表示される場合は、PCのWi-FiアダプターのIPv4アドレスを選びます。`localhost`や`127.0.0.1`はiPhone自身を指すため使いません。URLは`http://`です。

WindowsでWi-Fiのアドレスを確認する例:

```powershell
Get-NetIPAddress -InterfaceAlias 'Wi-Fi' -AddressFamily IPv4 |
  Select-Object IPAddress
```

特定のWi-Fiアドレスだけで待ち受ける場合（`<Wi-FiのIPv4>`を置換）:

```sh
pnpm preview --mode lan --host <Wi-FiのIPv4> --port 4174 --strictPort
```

`preview:lan`は全インターフェースで待ち受けます。ポート4174が使用中なら、自動的に別ポートに移らずエラーにします。LANモードではWorker inspector、Local Explorer、リモートbindings、トンネルを無効化します。ルーターのポート転送やネットワークの公開範囲変更は不要です。

PCを起動・Wi-Fi接続したまま、サーバーのターミナルを開いておきます。PCがスリープしたり、サーバーを停止したりすると接続できません。停止はターミナルで`Ctrl+C`。コードを変更した後は停止→`pnpm build`→再起動→Safari再読み込みの順で反映します。PCのIPはWi-Fiの変更や再接続で変わるため、毎回表示されたURLを確認してください。

## 最初の接続確認

1. Safariでアプリが表示され、上部が「API 接続済み」になる。
2. 接続の切り分けには`http://<PCのIP>:4174/api/v1/health`を開く。`{"ok":true,"phase":1}`が表示されれば、iPhone→PC→Workerの疎通ができている。
3. アプリへ戻る。自動で再生しなければYouTube標準の再生ボタンをタップする。
4. 下部の「次へ」を2回押して3本を確認し、「前へ」で戻る。検索・プロフィールは配置だけのため、押せない状態が正常。

**最初にミュートになるのは実装どおりです。** `PlaybackCoordinator.start()`が`mute()`してから`playVideo()`を呼びます。音声を出すときはYouTube標準のミュート解除を押してください。現実装では動画切り替え・再訪・タブ復帰で自動再生を試す際も再度ミュートし、音声オンの選択を次の動画へ引き継ぎません。端末の不具合を意味するものではありません。

PC自身からLANアドレスへ接続できても、iPhoneからの疎通確認が完了したことにはなりません。

## 開けない場合

| 状況 | 確認すること |
| --- | --- |
| Safariでサーバーに接続できない | サーバーが起動中か、URL/IP/ポート、両端末のWi-Fiを確認。まずPCでも同じURLを開く |
| PCでは開くがiPhoneでは開かない | Windowsの受信ルール、VPN、Wi-Fiの端末間通信制限を確認。ゲストWi-Fi・学校/会社などでは同じSSIDでも端末間通信を禁止している場合がある |
| アプリは開くがAPI未接続 | healthのURLとPCのサーバーログを確認 |
| アプリは開くがYouTubeだけ再生不可 | インターネット接続、Safariのコンテンツブロッカー、動画側の制限を確認。標準再生ボタン・再試行・別動画で切り分ける |
| 古い画面が出る | ビルドし直してサーバーを再起動し、Safariを再読み込みする |

ファイアウォール全体を無効にしないでください。受信許可が必要な場合は管理者が、使用するNode実行ファイル・TCP 4174・Wi-Fiインターフェース・同じサブネットだけに限定したルールを作成し、確認後に削除します。この起動コマンドはファイアウォールやWi-Fiプロファイルを書き換えません。端末間通信が禁止されたネットワークでは、端末間通信が許可された別のWi-Fiで確認してください。
