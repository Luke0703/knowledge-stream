# Knowledge Stream プロトタイプ仕様書

## 1. 目的
技術・科学・ものづくりなどの知識につながる短尺動画を、利用者が選択したジャンルに応じて縦型フィードで視聴できるWebサービスを開発する。

2026年10月20日時点では、本サービスの中心的な体験をスマートフォンから利用でき、管理者2名が動画・ジャンルを管理できる状態をプロトタイプ完成とする。

## 2. 完成条件
- トップ画面から複数ジャンルを選択し、すぐ動画フィードへ移動できる
- 選択したいずれかのジャンル（OR条件）に属する動画を表示する
- YouTube公式プレーヤーで動画を再生できる
- 縦方向のスワイプ/スクロールで1本ずつ切り替えられる
- 表示位置に応じて動画のロード・再生・停止を制御する
- 動画を最後まで再生した場合に「視聴済み」とする
- 未視聴動画を既視聴動画より優先する
- 保存・役立った・興味なし・分類が違う、の操作ができる
- 下部メニューの「動画」「設定」を切り替えられる
- 設定から選択ジャンルを変更できる
- 管理者専用画面から動画・ジャンルを管理できる
- スマートフォンのブラウザから利用できる

## 3. 一般利用者画面
### 3.1 トップ / ジャンル選択
初回利用時にジャンルを複数選択できる。選択完了後は直ちに動画フィードへ移動する。一般利用者のログインは要求しない。

### 3.2 動画フィード
YouTube公式プレーヤーを中心に、動画ジャンル、保存、役立った、興味なし、分類が違う等の操作を表示する。
CSSの scroll-snap 等は位置合わせに利用し、ロード・再生・停止・先読みはTypeScript側で制御する。
現在表示中と前後の少数動画だけをロード対象とし、大量のPlayerを同時生成しない。
自動再生がブラウザに拒否された場合にも操作不能にならないようにする。

### 3.3 下部メニュー
「動画」「設定」の2タブを基本とする。設定では現在のジャンルを確認・変更できる。独立したフィード設定画面は設けない。

## 4. ジャンル
複数選択時はOR条件。1本の動画は複数ジャンルに所属できる。初期ジャンルは管理者が決定する。

## 5. フィード生成
「興味なし」の動画を除外し、残りを未視聴・既視聴に分け、それぞれをランダム化して未視聴を先に表示する。未視聴を見終えた場合は既視聴も再表示対象とする。ジャンル変更時はフィードを再生成する。

## 6. 視聴履歴
YouTube Playerの再生終了イベントを受けた時点で視聴済みとする。MVPではlocalStorage等に保存し、端末間同期は行わない。

## 7. 評価
- 保存: 端末側に保存
- 興味なし: 端末側に保存し通常フィードから除外
- 役立った: サービス側の評価データとして記録
- 分類が違う: サービス側へフィードバックとして記録

詳細は実装時に再確認する。

## 8. YouTube連携
YouTube IFrame Player APIを利用し、動画ファイル自体はKnowledge Stream側で保存・再配信しない。
MVPはYouTube Video IDを中心に扱い、YouTube Data APIは必須としない。

## 9. 管理画面
一般利用者向け画面とは分離し /admin からアクセスする。管理者2名を想定。
- YouTube URLから動画追加
- 動画編集
- 有効/無効切り替え
- 複数ジャンル設定
- ジャンル追加・編集・有効/無効切り替え

一般利用者による動画投稿は実装しない。管理画面はCloudflare Access等で保護する。

## 10. データ
Cloudflare D1を利用する。

### videos
id, youtube_video_id, source, title(optional), enabled, created_at, updated_at

### categories
id, name, enabled, created_at

### video_categories
video_id, category_id

### feedback
id, video_id, client_id, type, created_at

動画とジャンルは多対多。DB変更はmigrationとしてGit管理する。

## 11. 技術構成
- Frontend: React + TypeScript + Vite
- UI: モバイルファーストSPA
- Backend: Cloudflare Workers
- Static assets: Cloudflare Workers Static Assets
- Database: Cloudflare D1
- Video: YouTube IFrame Player API
- Admin protection: Cloudflare Access
- Source control: Git / GitHub

## 12. 10/20版の対象外
TikTok、Instagram、AI自動分類、一般ユーザー投稿、動画直接アップロード、一般ユーザーログイン、端末間同期、コメント、本格広告配信、法人分析画面、高度な推薦。
広告UI確認が必要な場合のみダミー広告カードを追加してよい。

## 13. 実装フェーズ
1. 基盤・技術検証: React/TS/Vite/Workers、固定動画で縦フィードとYouTube Playerの実機検証
2. フィード: ジャンル選択、複数ジャンル、未視聴優先、視聴済み判定、ロード制御
3. D1: videos/categories/video_categories等を作り固定データから移行
4. 一般利用機能: 保存・役立った・興味なし・分類違い・設定・下部メニュー
5. 管理画面: 管理者保護、動画/ジャンル管理
6. 実機テスト・小規模実証
7. バグ修正・2026-10-20完成

## 14. 完成判定
管理者が動画を登録し、一般利用者がスマートフォンからジャンルを選択し、該当するYouTube動画を縦フィードで連続視聴できること。視聴済み・基本評価・ジャンル変更が動作し、管理画面の更新が利用者側へ反映されること。
